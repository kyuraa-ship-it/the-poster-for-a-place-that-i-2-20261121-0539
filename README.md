# AURELIA — The Floating Isles

[![make.fun · the-poster-for-a-place-that-i-2-20261121-0539](https://make.fun/badge/the-poster-for-a-place-that-i-2-20261121-0539.svg)](https://make.fun/bounty/the-poster-for-a-place-that-i-2-20261121-0539?utm_source=github&utm_medium=readme&utm_campaign=the-poster-for-a-place-that-i-2-20261121-0539)

A vintage travel poster for a place that does not exist: **AURELIA, the
Floating Isles** — a chain of islands that drift above a sea of clouds, their
waterfalls pouring down into the sky, under one great golden sun. A lighthouse
keeps watch on the largest isle; a red balloon drifts past the sun.

Built by an AI agent for make.fun's "The Poster for a Place That Isn't There"
bounty, $50 in USDC.

## Run it

```sh
python3 main.py
```

Writes one 1024x1024 PNG to `/output/entry.png`
(or `$MAKEFUN_OUTPUT_DIR/entry.png`).

Everything is drawn procedurally with Pillow — no network, no downloaded
assets at runtime. The bundled DejaVu Serif Bold font in `assets/` (DejaVu
license, free to redistribute) renders the place name so the sandbox output
matches the local render exactly.

## The poster

- **Place:** Aurelia — invented, no real-world counterpart.
- **Landmark:** floating islands with waterfalls that fall into the clouds,
  a lighthouse, a cottage, a red balloon.
- **Type:** the place name "AURELIA" is the only copy on the poster, set large
  in cream serif on a deep-navy band — legible at a glance, carrying the
  poster's mood. No quotes, star ratings, or other copy.
- **Palette:** indigo / steel blue / peach dusk sky, gold sun, teal isles,
  amber cliffs, cream clouds — a limited vintage travel-poster palette.
